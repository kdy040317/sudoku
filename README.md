# 아홉 칸 스도쿠

브라우저에서 바로 즐기는 스도쿠 게임입니다. HTML 파일 하나로 되어 있고, 설치나 빌드가 필요 없습니다.

**플레이:** https://sudoku-delta-gilt.vercel.app

## 기능

- 난이도 4단계 (쉬움 · 보통 · 어려움 · 전문가), 매번 해답이 하나뿐인 새 퍼즐 생성
- 선택한 칸의 행 · 열 · 박스 강조, 같은 숫자 강조
- 메모 모드 (Shift+숫자), 숫자를 넣으면 관련 칸의 메모 자동 정리
- 오류 표시 3가지 (정답과 비교 / 규칙 충돌만 / 표시 안 함), 실수 3회 제한
- 실행 취소, 지우기, 힌트 3회, 일시정지
- Web Audio로 만든 효과음 (켜기/끄기 가능)
- 진행 상황 자동 저장, 난이도별 기록 (플레이 수 · 완료 수 · 최고 기록)
- 다크 모드, 모바일 화면 지원

## 키보드

| 키 | 동작 |
|---|---|
| 1–9 | 숫자 입력 |
| Shift + 1–9 | 메모 입력 |
| 방향키 / WASD | 칸 이동 |
| Backspace / Delete | 지우기 |
| N | 메모 모드 켜기/끄기 |
| Ctrl + Z | 실행 취소 |
| P | 일시정지 |

## 실행

`index.html`을 브라우저로 열면 됩니다.
